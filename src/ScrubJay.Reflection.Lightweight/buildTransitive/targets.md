# `ScrubJay.Reflection.Lightweight.targets`
This file controls which behavior switches are available for `ScrubJay.Reflection.Lightweight`

## Options

### AnyGetHashCode Behavior

In a `<PropertyGroup/>` block:

- `<AnyGetHashCodeRefStructBehavior>XXX</AnyGetHashCodeRefStructBehavior>`
- Where XXX : Throw, Passthrough, Address (flag enum string parse)
