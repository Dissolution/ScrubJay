# `ScrubJay.Functional`

Provides `Option` and `Result` functional types for C#.

## Result Types

### `Result`

### `Result<T>`

### `Result<T,E>`

### `Ok<T>`

### `Error<E>`

## Option Types

### `Option`

Static utility class to assist with creating `Option<T>` instances.

### `Option<T>`

### `None`

None, nil, nothing, null

Represents the absence of a value. Every instance of `None` is exactly the same.

## Other Types

### `Unit`

A basic [unit](https://en.wikipedia.org/wiki/Identity_element)-type for C#. Every instance of `Unit` is exactly the same.
